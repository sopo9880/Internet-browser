# Internet Browser v0.2.5

- Android 설정 화면에 Chromium 설정 테마를 적용해 설정 진입 시 종료될 수 있는 문제를 수정했습니다. 설정은 별도 화면에서 열리며 웹 탭을 추가하지 않습니다.
- Android 브라우저 메뉴에 ‘영상 다운로드’를 추가했습니다. 동영상 외의 영역을 길게 눌러 메뉴가 표시되는 경우에도 ‘이 페이지의 영상 다운로드’로 영상 찾기를 열 수 있습니다. 사이트가 길게 누르기를 가로채는 경우 브라우저 메뉴를 이용하세요.
- 직접 영상도 실제 파일 내용을 확인한 후 저장한 영상에 등록합니다. HTML·로그인 페이지·오류 응답은 영상으로 등록하지 않으며, MP4·WebM 등 영상의 실제 형식으로 저장합니다.
- Android 업데이트의 설치와 저장 위치 열기가 같은 다운로드 폴더의 APK를 사용합니다. 복사본의 내용도 확인하며, 설치기를 열지 못해도 검증된 파일을 유지해 다시 시도할 수 있습니다.
- AdBlock 아래에 Video DownloadHelper의 공식 스토어 설치 카드를 추가했습니다. Chrome용 확장의 YouTube 다운로드 제한을 안내합니다.

Android 보안 프로그램의 설치 차단이 해제된다고 보장하지 않습니다. 이번 설치 경로 변경은 v0.2.5 설치 후 다음 업데이트부터 적용됩니다. 필요하면 공식 릴리스의 APK를 외부에서 내려받아 기존 앱 위에 설치할 수 있습니다.

## 검증 기록

릴리스 전 실제 빌드·서명·통제된 영상 테스트 결과를 여기에 기록합니다. 컴파일 성공은 Galaxy S23 Ultra / One UI 8.5의 실제 설치 및 길게 누르기 동작을 검증한 것으로 취급하지 않습니다.
