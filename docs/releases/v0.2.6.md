# Internet Browser v0.2.6

- 영상과 음성이 따로 제공되는 영상(YouTube, DASH, 음성 트랙이 분리된 HLS)을 **하나의 MP4 파일**로 저장합니다. 지금까지는 영상 파일과 음성 파일을 따로 저장해 두고 재생할 때 맞춰 돌렸기 때문에 소리가 어긋나거나, 다른 앱·갤러리에서 열면 소리가 나지 않았습니다. 이미 저장한 영상은 그대로 재생됩니다.
- 저장을 시작한 뒤 원본 탭을 닫거나 다른 페이지·다음 쇼츠로 넘어가도 **저장이 계속됩니다**. 영상 찾기와 화질 확인은 지금처럼 원본 페이지가 열려 있어야 합니다.
- 저장 중 네트워크가 잠시 끊기면 2초, 5초, 10초 간격으로 **자동으로 다시 시도**한 뒤에만 일시정지합니다. 큰 단일 파일은 받은 부분부터 이어서 받습니다.
- Android: YouTube를 연 채 홈 화면으로 나가거나 화면을 꺼도 **재생이 계속됩니다**(백그라운드 재생). 알림의 미디어 조작으로 일시정지할 수 있습니다. 소리가 있는 다른 사이트의 영상도 데스크톱 Chrome처럼 백그라운드에서 계속 재생됩니다.
- Android: 설정 > 일반의 **상세 설정**을 누르면 앱이 종료될 수 있던 문제를 수정했습니다. Chromium 설정을 Chromium 자체의 설정 열기 경로로 엽니다.
- 업데이트 설명이 길 때 한글이 글자 중간에서 잘려 깨질 수 있던 문제를 수정했습니다.

YouTube 쇼츠는 모바일 YouTube 사이트의 위아래 넘기기를 그대로 사용합니다. 영상 저장은 권한이 있는 콘텐츠에만 사용하세요. 암호화(DRM)된 영상은 저장하지 않습니다.

## 검증 기록

- 영상·음성 병합: 실제 H.264/AAC 영상으로 네 가지 저장 형태(조각 MP4, 절대 오프셋, DASH 구간 연결, YouTube 경로의 MPEG-TS→mux.js 변환)를 병합했습니다. 디코딩된 모든 영상·음성 프레임이 원본과 비트 단위로 같았고, 중간 탐색도 확인했습니다. Chromium 재생기에서도 병합 파일이 끝까지 재생되고 음성 전체가 디코딩됐습니다.
- YouTube 백그라운드 재생 스크립트: Chromium 페이지에서 화면 숨김 이벤트가 페이지 코드에 전달되지 않는 것을 확인했습니다.
- 위 항목은 기기 밖에서 확인한 결과입니다. Chromium 전체 빌드, Galaxy S23 Ultra / One UI 8.5에서의 상세 설정 진입, YouTube 백그라운드 재생, 저장 중 탭 이동은 릴리스 전에 실기기에서 확인해 여기에 기록합니다.
