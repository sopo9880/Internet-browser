# Internet Browser v0.2.4 — 구현·검증 중

아직 공개되지 않은 개발 버전입니다. 아래 범위의 실제 컴파일·동작·배포 파일 검증을 마친 뒤 릴리스합니다.

- 업데이트 다운로드 진행률과 받은 용량/전체 용량 표시. 다운로드 후 Android 보안 설정 화면을 열고 돌아와 같은 검증 파일로 설치를 계속합니다. 설치 권한 설정은 별도 버튼으로 유지합니다.
- APK의 패키지·서명 인증서·상위 버전 여부를 설치 전에 대조합니다. 파일 크기와 SHA-256 검사도 유지합니다. 이 검사가 기기의 보안 검사 통과를 보증하거나 기존 차단 원인을 확정하지는 않습니다.
- Windows는 설치 파일이 있는 폴더를 엽니다. Android는 검증 APK 복사본을 Download/Internet Browser에 저장하고 시스템 다운로드 화면을 엽니다. 보안 화면과 다운로드 화면은 기기에서 별도로 확인할 대상입니다.
- 브라우저 메뉴의 설정을 독립 화면으로 열고, 내부에서 일반 / 보안·링크 / 영상 다운로드 / 저장한 영상 / 업데이트 항목을 전환합니다. Android의 전용 WebContents는 열린 웹 탭 목록에 추가되지 않습니다. Windows는 주소창 없는 별도 설정 창을 사용합니다.
- 저장한 영상의 개별·다중 선택 삭제와 기록만 지우기를 구분합니다. 실제 파일 삭제는 되돌릴 수 없으며 확인창에서 제목·개수·확인 가능한 용량을 표시합니다. 완료된 서재 항목만 삭제하며 프로필 폴더를 재귀 삭제하지 않습니다.
- 열린 웹 탭을 사용자가 선택해 해당 탭만 영상 탐색합니다. 탭이 닫히거나 문서가 바뀌면 다시 선택해야 합니다. 시크릿 탭과 일반 탭은 프로필 범위를 분리합니다.
- Windows 영상 우클릭 및 Android 길게 누르기의 기존 영상 저장 항목을 화질 선택·영상 탐색 흐름으로 연결합니다. 사이트 자체 메뉴, 암호화 영상, 제공되지 않는 형식은 별도 제한이 있을 수 있습니다. 모든 사이트 지원을 주장하지 않습니다.

기존 앱을 삭제하지 않은 업데이트와 데이터 보존을 확인해야 합니다. Galaxy S23 Ultra / One UI 8.5에서 이전 버전의 업데이트가 차단되고 삭제 후 새 설치가 성공한 사실만 확인됐으며, 이전 차단 원인은 미확정입니다. 실기기 결과 없이 해당 문제가 해결됐다고 표시하지 않습니다.

기존 v0.2.2·v0.2.3 공개 파일과 인증서는 변경하지 않습니다. 배포 APK는 기존 인증서로 서명하며 정식 빌드와 서명·스테이징의 정확한 산출물을 그대로 배포합니다. 대응 소스와 원본 라이선스 고지를 함께 제공합니다.
