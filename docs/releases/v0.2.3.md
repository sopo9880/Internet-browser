# Internet Browser v0.2.3

- Android 앱 이름과 위젯 이름에 남아 있던 Titanium 표시를 Internet Browser로 수정했습니다. 완성된 APK의 앱 이름도 빌드·서명 전에 검사합니다.
- 앱 내부에 저장한 영상 재생 시 ‘파일 액세스 거부됨’이 발생하는 원인을 수정했습니다. 기존 영상은 이동하거나 삭제하지 않습니다. 영상과 분리된 음성 파일만 허용하며 브라우저 프로필의 다른 파일은 계속 보호합니다.
- Android의 `chrome://internet-browser/` → **링크 열기**에 **웹 링크를 외부 앱으로 자동 열지 않기**를 추가했습니다. 기본으로 켜져 있으며 즉시 적용됩니다. HTTP(S), `intent:`와 앱 전용 링크의 외부 앱 전환을 차단합니다. 전화·문자·이메일 링크와 업데이트 설치는 별도로 동작합니다. 앱 전용 링크에 웹 주소가 없으면 열리지 않을 수 있습니다.

기존 앱을 삭제하지 않고 업데이트하세요. 삭제하면 앱 내부에 저장한 영상과 설정이 지워질 수 있습니다.

갤럭시 S23 울트라·One UI 8.5에서 v0.2.2의 기존 앱 업데이트는 보안 차단이 보고됐고, 사용자는 이전 앱 삭제 후 새 설치와 웹 탐색이 성공했다고 확인했습니다. 이 결과만으로 이전 차단 원인이나 오탐 여부를 확정할 수는 없습니다. v0.2.3의 실기기 업데이트·재생·외부 앱 전환 확인은 해당 버전의 검사 기록에서 별도로 구분합니다.

배포 APK·EXE는 정식 빌드 산출물을 재빌드·재서명 없이 재사용합니다. 체크섬, 원본 라이선스 고지와 해당 빌드의 소스 묶음을 함께 제공합니다. Android 실기기 검증은 기존 합의대로 릴리스 후 진행하며, 설치·데이터 보존·저장 영상 재생·외부 앱 전환 설정을 확인합니다. 실제 확인 전에는 실기기 검증을 통과했다고 표시하지 않습니다.
