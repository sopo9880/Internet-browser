# Internet Browser v0.2.1 — 실기기 검증용 릴리스

요청에 따라 v0.2.1을 먼저 배포합니다. 발견되는 오류는 수정 후 **v0.2.2**에서 해결할 예정입니다.

## 첨부 파일

- `Internet-browser-Android-v0.2.1.apk`: 기존 Chromium 네이티브 빌드를 v0.2.0과 동일한 Android 공식 인증서로 서명한 APK입니다. 새로운 Chromium 소스 빌드가 아닙니다.
- `Internet-browser-Windows-Setup-v0.2.1.exe`: 기존 **Flutter 기반 Windows 브라우저**를 v0.2.1로 빌드한 설치 프로그램입니다. Windows까지 Chromium 엔진으로 교체됐다는 뜻이 아닙니다.
- `SHA256SUMS.txt`: 첨부된 두 설치 파일의 SHA-256 해시입니다.

## 중요: 기능 통합 검증 미완료

Android Chromium APK의 서명과 파일 무결성 검증은 성공했지만, 실제 브라우징, **AdBlock/MV3 확장 설치 및 광고 차단**, **ByeDPI**, 영상 재생·다운로드, 탭/주소창 연결, 기존 사용자 데이터 이전은 **실기기·통합 검증을 통과하지 않았습니다**. 일부 기능이 작동하지 않거나 실행 오류가 발생할 수 있습니다. CI의 네이티브 빌드 작업은 성공했지만 전체 통합 검증은 통과하지 못했습니다.

**기존 v0.2.0 데이터를 백업한 후**, 가능하면 보조 Android 기기 또는 분리된 테스트 환경에서 먼저 설치해 주세요. 앱 삭제는 기존 앱 데이터를 지울 수 있습니다. 인플레이스 업데이트 시 데이터 이전이 안전한지는 아직 확인되지 않았습니다.

## 테스트 후 피드백

Android에서 실행·사이트 접속·주소창·탭 전환·AdBlock 설치·ByeDPI·영상 다운로드·오프라인 재생을 확인해 주세요. 문제가 있다면 기기/Android 버전, 재현 절차와 오류 화면을 GitHub Issues로 보내 주시면 v0.2.2 수정에 반영합니다.
